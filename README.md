# Scrutester
Battery powered tester for electrical inspection in formula student. 

## Functions
* Voltage source 0 .. 60V, 1A max
* Current source 0 .. 10A, 5V max
* Milliohm resistance measurement with 4 wire connection, 1A measurement current
* Isolation resistance measurement with adjustable test voltage up to 1000V DC
* Voltmeter &pm; 1000V
* Amperemeter &pm; 10A
* Charging from output terminals
